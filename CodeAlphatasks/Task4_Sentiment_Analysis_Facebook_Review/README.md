# Facebook Reviews Sentiment Analysis 📊

A comprehensive sentiment analysis of **Facebook Mobile App** reviews using Python, Pandas, and WordCloud visualization.

[Facebook Review Analysis](https://github.com/Riddhi712/CodeAlpha_Task_4_sentiment_analysis/blob/main/Facebook%20review.png)

---

## 📋 Project Overview

This project analyzes **355,807+ Facebook app reviews** to understand user sentiment, identify key pain points, and track trends over time.

### Key Insights

- **Overall Sentiment**: **Mildly Positive** (Average Rating: **3.89/5**)
- **Positive Reviews**: ~70.3%
- **Negative Reviews**: ~24.1%
- **Recent Trend (May 2026)**: Strong **negative shift** — users are increasingly frustrated.

---

## 🚨 Major Issues Identified

| Issue                    | Frequency | User Sentiment |
|-------------------------|---------|--------------|
| Too many ads            | Very High | Extremely Negative |
| Account suspensions/bans| High     | High Anger |
| UI changes (bottom nav) | High     | Frustrated |
| Bugs & glitches         | High     | Annoyed |
| Storage bloat           | Medium   | Negative |
